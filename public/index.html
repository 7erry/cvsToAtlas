MongoDB CSV-to-Atlas importer Smart schema and join detection

Import CSV data into Atlas faster.

Upload one or more CSVs, inspect the headers, pick a join field, and import clean nested MongoDB documents with recommended indexes.

Dots become nested documents and numeric path segments build arrays.
Common fields are ranked so related CSVs can merge into one collection.
Values that look like JSON, booleans, or numbers are coerced automatically.

Prepare import

Select CSVs, review detected headers, then import into Atlas.

Same join value across files is merged with deepMerge. Optional for one file (also deduplicates duplicate keys in that file).

Database is taken from MONGODB_DB (default csv_to_atlas).
